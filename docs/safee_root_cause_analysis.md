# SAFEE Financial Fact Extraction — Root Cause Analysis Report

## Executive Summary
During the ingestion of test document `finacacial fact testing nlp 2.pdf` (DocumentId: 21), 46 financial and operational observations were expected, but only 36 records were returned to SQL with approximately 2 fully correct facts, 20 NeedsReview records, and 9 nonfinancial false positives.
This report traces the 20 confirmed production defects to their root causes across the pipeline stages.

---

## Confirmed Defects & Stage-by-Stage Root Cause Tracing

| # | Confirmed Symptom | First Faulty Stage | Root Cause Detail | Resolution Implemented |
|---|---|---|---|---|
| 1 | Every stored source location is identified as "Paragraph", including information originating from tables. | `local-extractor.js` | `extractTablesFromPdfText` only matched the literal phrase `metric count amount`. All real financial tables resulted in `tables: []`, dumping all document lines into 4 large paragraph blocks. | Implemented coordinate-aware layout extraction (`pdf-layout-adapter.js`) extracting tables with headers, row/col coordinates, and separating tables from narrative paragraphs. |
| 2 | Annual tables with two financial year columns extract only one value per row. | `matrix-unpivoter.js` & `local-extractor.js` | Flat text paragraphs merged table lines (`Revenue 15.50 20.75`), and the paragraph extractor only picked the first value (`15.50`). | Reconstructed multi-column table grid; `matrix-unpivoter.js` iterates over all populated `valueColumns` in each row. |
| 3 | Entire quarterly financial table (9 observations) missed. | `local-extractor.js` | Quarterly table lines could not be segmented into sentences by sentence segmenter, so they were dropped by the paragraph extractor. | Proper table grid extraction extracts all 3 quarterly rows across 3 metrics (9 observations total). |
| 4 | Table-level currency and scale lost. | `table-island-detector.js` & `context-graph.js` | `detectTableIslands` did not preserve `contextText` or `note` metadata on island objects, losing the caption "All monetary amounts are expressed in AED millions." | Propagated `contextText` and `note` across table islands; table context inherits scale multiplier (1,000,000) and currency (`AED`). |
| 5 | Revenue of AED 15.50 million stored as 15.50 instead of 15500000. | `matrix-unpivoter.js` | Inherited scale multiplier was lost due to missing table context (Defect 4). | Table context scale multiplier (1,000,000) is applied to monetary cells, correctly yielding 15,500,000. |
| 6 | Unknown metrics extracted without associated entity, period, and currency. | `context-graph.js` | When unfamiliar metrics were extracted in flat text paragraphs, surrounding table context was absent. | Scoped context graph associates row-level or table-level entity, period, and currency with unknown metrics. |
| 7 | Multiple companies assigned the same entity (Astravion leaked into Nexovanta, Velmora, Quantivex). | `context-graph.js` & `paragraph-extractor.js` | No boundary reset between sections or rows when entity changed. | Explicit entity transition guard resets active entity, period, and currency whenever a new company is introduced. |
| 8 | Entire table rows concatenated into metric labels. | `paragraph-extractor.js` | Smashed table rows parsed as narrative text treated entire row strings (e.g. `Astravion Technologies Capital Expenditure FY 2026`) as metric labels. | Table cells are strictly isolated in column grid; metric label is clamped to the cell in the designated Metric column. |
| 9 | Total Assets of 8,500,000 stored as 850,000. | PDF text layout & `numeric-normalizer.js` | PDF text item split `8,500,00\n0` across lines. Flat parser read `8,500,00` dropping the trailing zero. | Line-wrap cleaner and `parseNormalizedNumberString` merge wrapped digits (`8,500,00` + `0` -> `8500000`). |
| 10 | Indian number 1,25,00,000 stored as 1,250,000 instead of 12,500,000. | PDF text layout & `numeric-normalizer.js` | PDF text item split `1,25,00,00\n0` across lines; Indian grouping regex was missing wrapped digit handling. | Indian grouping regex `^\d{1,2}(,\d{2})+(,\d{3})(\.\d+)?$` and line-wrap normalization correctly parses to 12,500,000. |
| 11 | Narrative facts lost reporting period. | `sentence-segmenter.js` | Line wrap `for FY\n2025` split the period across visual lines, breaking period regex matching. | `cleanVisualLineWraps` joins visual wraps, preserving `for FY 2025` in the narrative clause. |
| 12 | Repeated metrics across different periods ("in FY 2025 and" became metric name). | `paragraph-extractor.js` | In "Quantivex reported revenue of AED 12M in FY 2025 and AED 18M in FY 2026", left-span before second candidate was `in FY 2025 and`. | Stop-word/period span detection detects coordinated repeated metric and inherits `revenue` for the second candidate. |
| 13 | Meaningful words removed from unfamiliar metric names. | `paragraph-extractor.js` | Overly aggressive metric cleaner stripped adjectives. | Metric cleaner preserves full financial noun phrases (e.g. "Digital Infrastructure Recovery Benefits"). |
| 14 | Actual and Budget columns not separated. | `matrix-unpivoter.js` & `role-classifier.js` | Multi-level header paths were not distinguishing Actual vs Budget columns. | `role-classifier.js` and `matrix-unpivoter.js` classify header paths into `reportingBasis: 'Actual'` and `reportingBasis: 'Budget'`. |
| 15 | Document version numbers extracted as financial facts. | `candidate-detector.js` | "Document Version: 1.0" was classified as a financial candidate. | Added `VERSION_CUE_RE` classifying version numbers as `DocumentVersion` (`isFinancial: false`). |
| 16 | Nonfinancial testing summary counts assigned AED currency and marked Validated. | `candidate-detector.js` & `document-layout.js` | "Expected testing results ... Total 46" was parsed as financial candidates and inherited AED currency. | Tables with "Expected facts/testing results" are tagged `isNonFinancial: true` and excluded from fact extraction. |
| 17 | Incorrect facts assigned confidence scores of 0.92/0.98. | `evidence-validator.js` | Confidence scoring assigned 0.98 purely on presence of candidate without validating metric semantics. | Mandatory check: invalid metric labels (e.g. `in FY 2025 and`) receive `criticalFail = true, confidence = 0.0`. |
| 18 | Incorrect entity/metric relationships marked Validated and Approved. | `evidence-validator.js` | Missing entity, missing period, or missing currency for amounts did not downgrade validation status. | Missing required context marks facts as `NeedsReview` with confidence capped at 0.65. |
| 19 | Original numeric evidence replaced with normalized values. | `sql.js` & persistence | `RawValue` was overwritten by normalized number string. | `RawValue` preserves original text token (`15.50`, `1,25,00,000`), separate from `NormalizedValue`. |
| 20 | Missing context distinction between unresolved and validated facts. | `validation/evidence-validator.js` | Validated and NeedsReview statuses were conflated. | Enforced clear separation: complete evidence = `Validated`, missing context = `NeedsReview`. |
